# AGENTS.md

This repository is an agent skill: **dialogue-animator**. It turns a folder containing `dialogue.md` into an animated 2D character video. It is written for any coding agent: Claude Code, Codex, Gemini CLI, Cursor, Aider, Continue, or a human with a terminal.

## If you were asked to make a video
Read `SKILL.md` and follow it. The whole procedure is one loop:

```bash
node bin/da.mjs next <project>       # says the ONE thing to do next. Do it, run this again, stop at DONE.
```

The user brings a folder: `dialogue.md` (dialogue and narration, sound cues as `@sfx name`), and if they have them `audio/`, `sfx/`, `music/`, `characters/`. `SKILL.md` has the table.

There are no model-specific features, tools or sub-agents to rely on. Optional extras such as whisper, Playwright or a second reviewer are only described as optional.

## If you were asked to change the code
- Runtime: Node ≥ 20, ES modules (`.mjs`), no build step, no TypeScript. The only npm dependency is `@napi-rs/canvas`. ffmpeg comes from PATH, `FFMPEG_PATH`, `ffmpeg-static` or Python `imageio-ffmpeg`.
- `src/engine/` is the renderer core. It must stay **pure and browser-safe**: no `node:` imports and no `Math.random`, because the same files run in the preview page and in Playwright. Randomness comes from `math.mjs` hashes seeded by the storyboard.
- The renderer reads only `build/storyboard.json` plus the style pack. If you add a feature, add it to the storyboard (director) and the schema (`schemas/storyboard.schema.json`), then draw it in the engine.
- Data contracts are JSON Schema files in `schemas/`. Validate with `src/lib/schema.mjs`, a small built-in validator; any draft 2020-12 validator also works.
- Tests: `npm test` (node:test, no network). Add a test for every bug you fix. Add the bug to `docs/TROUBLESHOOTING.md` if a user could hit it.
- Keep `SKILL.md` short and procedural. Put details in `docs/`.
- The decisions belong in code, not in the instructions: `src/next.mjs` holds the order of the steps. A new pipeline step goes there too, and `test/any-agent.test.mjs` must keep passing. It is an "agent" with no judgment that only obeys `da next`.
- Assets must be MIT/CC0 or generated by code. Fonts are OFL and stay unmodified in `fonts/` with their `OFL.txt`.

## Layout
```
SKILL.md, AGENTS.md, README.md, LICENSE
bin/da.mjs                CLI entry (one sub-command per pipeline step)
src/next.mjs              `da next`: reads the folder, says the one thing to do next
src/lib/                  util, ffmpeg discovery, wav, text, font cmap check, schema validator
src/project/              config/decisions, dialogue parser, lexicon, colours, casting, init, answers
src/audio/                babble voice, timing/alignment, whisper helper, music synth, sound effects, mix
src/director/             storyboard (all editing rules), lint
src/engine/               pure Canvas2D renderer: render, env, state, camera, materials, bodies/, props, settings, captions, transitions, fx
src/render/               node-canvas + playwright adapters, stills, video render, workers
src/qa/                   qa checks, contact sheets, side-by-side compare
src/preview/              zero-dependency preview server + page
src/style/                style pack loader + CLI (list/new/check/preview/palette)
schemas/                  project, dialogue, character, words, style-pack, storyboard
styles/<id>/style.json    style packs (kesik-kagit = default, jole, riso-cizgi)
fonts/                    OFL fonts with their licences
docs/                     reference docs (SKILL.md links here)
examples/cay-krizi/       example project + rendered output
test/                     node:test suites
```
