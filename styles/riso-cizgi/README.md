# Riso Çizgi (Riso Line)

Risograph print: one blue monoline that trembles twice a second, pink and yellow fills printed slightly off-register, coarse halftone dots, slow editorial camera.

- id: `riso-cizgi` · family: `line` · body: `lanky-line`
- palette (4 colours): `#F6F1E7` `#1F5AA6` `#FFD400` `#FF48B0`
- motion: characters at 30 fps, push-in 0.08 %/frame, pan ≤ 8 px/frame
- transitions: cut = dissolve, scene = ink-wipe (14 f)
- captions font: Fraunces 600
