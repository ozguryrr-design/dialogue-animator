# Fonts

All fonts are unmodified variable fonts from the Google Fonts repository (github.com/google/fonts), licensed under the **SIL Open Font License 1.1**. Each licence and copyright notice is in the `OFL.txt` next to the font. They are registered under aliases (`DA Baloo 2`, `DA Fraunces`, `DA Noto Sans`) so a system font with the same name cannot replace them.

| folder | family | used by | covers |
|---|---|---|---|
| `baloo2/` | Baloo 2 (variable weight 400–800) | kesik-kagit, jole captions | Latin incl. Turkish, Latin Extended, Vietnamese, Devanagari |
| `fraunces/` | Fraunces Italic (variable) | riso-cizgi captions | Latin incl. Turkish, Latin Extended |
| `notosans/` | Noto Sans (variable weight/width) | fallback in every pack | Latin, Cyrillic, Greek, Vietnamese and more |

For CJK, Arabic, Hebrew and other scripts, add a covering OFL font to your pack (docs/STYLE_PACK.md). `da doctor` lists the characters that are missing.
